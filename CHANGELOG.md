# Changelog

## 0.1.0

- First version: bulk check of up to 50 names per request with CSV export, a local watchlist that is re-checked on a timer and sends a notification when a status changes, a tray icon (check the clipboard, open the tools, quit), the website's tools in a second window, optional Pro+/Business API key in the system keyring. English, Spanish, French and German. On Linux the package is named `namedaemon` (`tauri.linux.conf.json`) and the menu entry reads "NameDaemon".
